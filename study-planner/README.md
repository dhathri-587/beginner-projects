# 📚 Study Planner

A simple and modern web-based Study Planner designed to help students organize their study tasks and track their progress.

## ✨ Features

* Add study tasks
* Add subject, date and time
* Set task priority
* Mark tasks as completed
* Delete tasks
* Filter pending and completed tasks
* View task statistics
* Dark mode
* Local storage support
* Responsive design for mobile and desktop

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* Browser Local Storage

## 🚀 How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Double-click `index.html`.
4. The Study Planner will open in your browser.
