# Interactive Number Guessing Game with Analytics

A beginner-friendly Python project built inside a Jupyter Notebook. It tests your guessing skills, tracks how long you take to make decisions, and visually plots your performance analytics.

## Features
 **Interactive Gameplay:** Fully functional guessing interface running inside a notebook environment.
 **Error Handling:** Built-in validation to prevent code crashes if you accidentally type text instead of a number.
 **Data Analytics:** Uses `matplotlib` to plot your guessing history line against the hidden target number.
